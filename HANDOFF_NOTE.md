## 3. Запуск

```bash
npm start   # → http://localhost:3000
```

Приложение работает только через сервер; открытие `index.html` с диска (`file://`) не поддерживается — фронтенд ходит за данными на `/api/locales`.

## 4. Формат данных `locales.json`

Массив записей. Пример:

```json
{
  "code": "en-AU",
  "languageCode": "en",
  "countryCode": "AU",
  "flag": "🇦🇺",
  "language": { "ru": "Английский", "en": "English" },
  "country": { "ru": "Австралия", "en": "Australia" },
  "currency": "AUD",
  "tld": ".au",
  "capital": "Canberra",
  "timezones": ["UTC+10:00"]
}
```

- `code` = `<ISO 639-1 язык>-<ISO 3166-1 alpha-2 страна>`;
- `language` / `country` — названия в двух языках интерфейса `{ ru, en }`;
- `capital` и `timezones` — опциональные поля (массив таймзон, отображается первая); отсутствующие поля (undefined/null/'') отображаются как «—» (M3);
- тестовая локаль `na-NR` (Науру) добавлена специально без поля `capital` — для проверки «—»;
- файл перечитывается сервером на каждый запрос — правки данных видны без перезапуска.

## 6. Принятые решения / ограничения

- Ноль npm-зависимостей; vanilla `node:http` на сервере, vanilla JS на клиенте.
- ES Modules (`"type": "module"` в `package.json`).
- Данные живут внутри бэкенда (`locales.json`), правятся вручную; внешние API в рантайме не используются.
- Флаги — эмодзи, внешние картинки не используются.
- Защита от path traversal в раздаче статики (`startsWith(ROOT)` + нормализация URL).

- 15 записей, коды: `en-US, en-GB, en-AU, en-CA, ru-RU, fr-FR, de-DE, es-ES, it-IT, pt-BR, ja-JP, zh-CN, ko-KR, ar-SA, nl-NL`;

- `/`, `/app.js`, `/style.css` отдают 200 с корректными Content-Type;
- `locales.json` валиден, `app.js` проходит `node --check`;
- поиск: `au` → en-AU, `росси` → ru-RU, `англ` → 4 англоязычные.

Тест M3:

- 16 записей (добавлена `na-NR` без `capital`);
- `na-NR`: столица → «—», tld → `.nr`, currency → `AUD`;
- en-AU: currency → `AUD`, tld → `.au`;

Тест M4 (сортировка):

- по «Код» asc: `ar-SA … zh-CN`, desc: `zh-CN … ar-SA`;
- по «Столица» asc: `na-NR:—` первая (сортируется по «—»);
- колонка «Флаг» не сортируется (нет `data-key`);
- сортировка применяется к отфильтрованному поиском списку;
- индикатор ▲/▼ в активном заголовке.

Тест M5 (локализация, ошибки, таймзоны):

- RU→EN: заголовки/названия меняются без перезагрузки, активная кнопка подсвечена;
- поиск и сортировка работают на EN;
- сервер остановлен → блок ошибки, таблица скрыта; «Повторить» после запуска сервера восстанавливает данные;
- en-AU (8 таймзон) → «UTC+10:00 · всего 8»; na-NR (1) → «UTC+12:00».
